# 화성시남부노인복지관 후원물품 수입·사용 관리대장

> **에어비앤비(Airbnb) 스타일의 깔끔한 사진 카드 피드형 후원물품 관리도구**  
> 복지관 내 모든 부서 직원들이 언제든 사진과 함께 잔여 재고를 쉽게 확인하고, **"어디 팀에서 몇 개 무슨 목적"**으로 사용하는지 클릭 몇 번으로 간편하게 등록하고 투명하게 공유할 수 있는 시스템입니다.

---

## 📌 1. 실행 방법

1. 폴더 내 **`실행하기_관리대장.bat`** 파일을 더블 클릭하거나,
2. **`index.html`** 파일을 더블 클릭하면 기본 웹 브라우저(크롬/엣지)에서 바로 실행됩니다.
- 복잡한 금액 관련 항목을 모두 제거하여 화면이 직관적이고 깔끔합니다.
- 데이터는 브라우저(로컬 스토리지)에 자동 저장되며 언제든 엑셀(`.xlsx`)로 다운로드할 수 있습니다.

---

## 🌟 2. 주요 기능 및 사진 삽입 안내

### 1) 모든 품목에 즉시 사진 삽입 / 변경 (신규 추가!)
- **카드에서 바로 사진 변경**: 모든 후원물품 카드 우측 하단에 **`[📷 사진 변경]`** 버튼이 항상 노출되어 있어, 카드를 굳이 열지 않고도 클릭 한 번으로 내 컴퓨터나 스마트폰에 있는 실제 후원물품 사진을 바로 넣을 수 있습니다.
- **상세 팝업에서도 변경 가능**: 물품 클릭 시 나타나는 사진 영역이나 사진 아래 **`[📷 실제 후원물품 사진 넣기 / 변경]`** 버튼을 눌러 사진을 교체할 수 있습니다.
- **스마트 자동 압축**: 스마트폰이나 카메라로 찍은 5~10MB 대용량 고화질 사진도 브라우저에서 자동으로 최적화(웹 표준 800px 해상도) 압축하여 저장하므로, 수십 장의 실제 사진을 등록해도 느려짐 없이 빠르고 안전하게 보존됩니다.

### 2) 현장 표준 용어 적용
- **반출** ➔ **사용** (사용 등록, 사용 이력, 사용대장)
- **입고** ➔ **수입** (수입 등록, 수입일자, 수입 수량)

### 3) 에어비앤비(Airbnb) 사진 카드 피드
- 모든 후원물품이 1:1 사진과 함께 감각적인 카드 피드로 나열됩니다.
- 각 카드 상단에 **창고 위치 배지**(예: 📍 `공유냉장고`, 📍 `1층 창고`)와 **실시간 재고 상태**(예: `재고 25포`, `재고부족`, `품절`)가 한눈에 표시됩니다.
- 카드 하단에 가장 최근에 사용된 내역(예: `최근: 문화복지팀 · 5박스 (공유냉장고 채움)`)이 바로 보입니다.

### 4) 창고 및 카테고리 필터
- **보관 창고 (6종)**: `지하 1층 창고`, `1층 창고`, `MDF실`, `공유냉장고`, `공유냉장고 옆 서랍`, `3층 창고`
- **물품 분류 (7종)**: `식품`, `식재료`, `생활용품`, `도서`, `잡화`, `가구`, `기타`
- 상단 탭과 알약형 필터 버튼을 클릭하여 원하는 장소/분류만 모아서 볼 수 있습니다.

### 5) 물품 클릭 시 간편 사용 등록 & 이력 확인
카드를 클릭하면 상세 팝업이 열립니다.
1. **사진 및 재고 확인**: 선명한 물품 사진과 함께 **현재 보관 재고**를 큰 글씨로 확인.
2. **물품 사용 등록**:
   - **사용 부서**: `운영지원팀`, `사회참여팀`, `문화복지팀`, `지역돌봄팀`, `주간보호센터`, `타기관 (직접 입력)`
     - *타기관 선택 시 기관명을 직접 타이핑할 수 있는 입력란이 즉시 나타납니다.*
   - **사용 수량**: `[-]` `[+]` 증감 버튼으로 손쉽게 수량 조절
   - **사용 목적**: 원클릭 추천 버튼(`공유냉장고 채움`, `어르신 프로그램 지원`, `경로식당 배식` 등) 또는 직접 입력
   - **[사용 확정]** 버튼 클릭 시 재고가 자동으로 차감됩니다.
3. **사용 이력 목록**:
   - 하단에 **"어디 팀에서 몇 개 무슨 목적"**으로 가져갔는지가 시간순으로 깔끔하게 카드형태로 나열됩니다.

### 6) 새 후원물품 수입 등록
- 상단 **`[후원물품 수입 등록]`** 버튼 클릭
- 내 컴퓨터에 있는 사진 파일을 선택하여 업로드 가능 (사진이 없어도 카테고리별 기본 고화질 사진 자동 지정)
- 품명, 분류, 보관창고, 수입 수량, 단위, 후원처, 수입일자 입력 후 저장

### 7) 전체 사용대장 & 엑셀 다운로드
- 상단 **`[전체 사용대장]`** 버튼: 복지관 전체 사용 내역을 테이블로 확인
- **`[엑셀 저장]`** 버튼: 금액 없이 실무에 꼭 필요한 수량 중심의 **재고현황 시트**와 **사용대장 시트**가 담긴 엑셀 파일(`.xlsx`) 자동 다운로드
