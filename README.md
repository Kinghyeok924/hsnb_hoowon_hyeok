> **에어비앤비(Airbnb) 스타일의 깔끔한 사진 카드 피드형 후원물품 관리도구**

## 📌 1. 실행 방법 (Quick Start)

별도의 백엔드 서버나 복잡한 설치 과정 없이, 웹 브라우저가 있는 모든 PC에서 즉시 실행됩니다.

1. **원클릭 실행**: 폴더 내 **[`실행하기_관리대장.bat`](실행하기_관리대장.bat)** 파일을 더블 클릭
2. **직접 실행**: **[`index.html`](index.html)** 파일을 크롬(Chrome) 또는 엣지(Edge) 브라우저로 열기

- **서버리스 동작**: 모든 데이터는 브라우저 로컬 저장소(`localStorage`)에 실시간 자동 보존됩니다.
- **오프라인 지원**: 인터넷 연결 없이도 로컬 환경에서 재고 조회, 사용 등록, 엑셀 출력이 가능합니다.

## 🌟 2. 주요 핵심 기능

### 1) 에어비앤비(Airbnb) 스타일 사진 카드 피드
- **1:1 비율 사진 중심 갤러리**: 텍스트 위주의 딱딱한 스프레드시트 대신, 실제 물품 사진과 함께 감각적인 카드 피드로 재고 현황을 직관적으로 확인합니다.
- **창고 위치 & 재고 상태 배지**:
  - 상단 배지: 보관 창고 위치 (📍 `1층 창고`, 📍 `공유냉장고`, 📍 `MDF실` 등)
  - 하단 배지: 실시간 재고 수량, 재고 부족 경고(`3개 이하`), 품절(`0개`) 자동 강조
- **최근 사용 내역 미리보기**: 카드를 열지 않아도 직전 사용 내역(예: `최근: 문화복지팀 · 5박스 (공유냉장고 채움)`)이 카드에 바로 노출됩니다.

### 2) 모든 물품에 즉시 사진 삽입 / 변경
- **카드에서 원클릭 사진 변경**: 카드 우측 하단 **`[📷 사진 변경]`** 버튼을 눌러 내 컴퓨터/스마트폰의 실제 후원물품 사진으로 즉시 교체 가능.
- **상세 모달에서도 사진 교체**: 품목 클릭 후 나타나는 사진 영역이나 전용 버튼으로 언제든 사진 변경 지원.
- **스마트 자동 압축 엔진**: 5~10MB 고화질 사진도 브라우저 캔버스에서 자동으로 웹 최적화(최대 800px, JPEG 압축)하여 저장하므로, 수십 장의 사진을 등록해도 브라우저 용량 초과 없이 빠르고 가볍게 구동됩니다.

### 3) 창고 및 카테고리 멀티 필터링
- **보관 창고 필터 (6종)**: `지하 1층 창고`, `1층 창고`, `MDF실`, `공유냉장고`, `공유냉장고 옆 서랍`, `3층 창고`
- **물품 분류 탭 (7종)**: `식품 🍜`, `식재료 🍚`, `생활용품 🧴`, `도서 📚`, `잡화 🛍️`, `가구 🪑`, `기타 📦`
- 상단 캡슐형 통합 검색창을 통해 **품명, 후원자명, 창고 위치**를 실시간으로 빠르게 검색할 수 있습니다.

### 4) 간편 사용 등록 & 투명한 이력 관리
카드를 클릭하면 상세 팝업이 열리며, 10초 만에 사용 등록을 완료할 수 있습니다.
- **사용 부서 선택**: `운영지원팀`, `사회참여팀`, `문화복지팀`, `지역돌봄팀`, `주간보호센터`, `타기관 (직접 입력)`
  - *타기관 선택 시 기관명(예: 남양지역아동센터 등)을 직접 타이핑할 수 있는 입력란이 즉시 활성화됩니다.*
- **수량 조절**: 증감 버튼(`-`, `+`) 또는 숫자 직접 입력
- **사용 목적 추천 칩**: `공유냉장고 채움`, `어르신 프로그램 지원`, `경로식당 배식`, `취약계층 긴급배부`, `기관 행사 지원` 클릭 한 번으로 입력
- **[사용 확정]** 클릭 시 현재 재고가 자동으로 차감되며, 하단 사용 이력 타임라인에 즉시 영구 기록됩니다.

### 5) 신규 후원물품 수입 등록
- 상단 **`[+ 후원물품 수입 등록]`** 버튼 클릭
- 실제 사진 첨부(사진 미첨부 시 카테고리별 고화질 기본 사진 자동 매칭)
- 품명, 분류, 보관창고, 수입 수량, 단위, 후원자(처), 수입일자, 참고사항 입력 후 원클릭 등록

### 6) 엑셀(.xlsx) 내보내기 & 전체 사용대장
- **전체 사용대장 모달**: 복지관 전체 부서의 모든 사용 기록을 시간순 테이블로 한눈에 조회
- **실무 맞춤형 엑셀 파일 다운로드**: 복잡하고 불필요한 금액 항목을 배제하고, 실무 감사 및 전자결재 보고에 꼭 필요한 수량 중심의 2개 시트로 구성된 엑셀 파일 자동 생성:
  1. `후원물품재고현황` 시트: 품명, 분류, 창고, 총수입수량, 총사용수량, 현재재고, 후원처, 수입일자
  2. `후원물품사용대장` 시트: 사용일시, 사용부서, 품명, 사용수량, 보관창고, 사용목적, 담당자

## 🎨 디자인 시스템 (Design Tokens)

본 시스템은 [`DESIGN.md`](DESIGN.md)에 정의된 **Airbnb Light Theme** 디자인 철학을 충실히 반영하여 제작되었습니다.

| 토큰명 | 색상 코드 | 역할 및 용도 |
| :--- | :--- | :--- |
| **Rausch** | `#ff385c` | 브랜드 포인트 컬러, 사용 확정 CTA, 강조 배지 |
| **Hof** | `#222222` | 기본 텍스트, 카드 타이틀, 활성 버튼 배경 |
| **Foggy** | `#6a6a6a` | 보조 텍스트, 비활성 탭, 설명 라벨 |
| **Bebe** | `#ebebeb` | 얇은 구분선, 테두리, 카드 디바이더 |
| **Faint** | `#f7f7f7` | 배경 캔버스, 호버 서피스, 폼 필드 배경 |
| **White** | `#ffffff` | 메인 헤더, 모달 서피스, 팝업 카드 |

- **카드 비율**: 1:1 정사각형 사진 영역 + 12px 둥근 모서리
- **컨트롤 형태**: 알약형(Pill, `border-radius: 9999px`) 버튼 및 검색 캡슐
- **폰트**: 가독성이 뛰어난 한국어 표준 `Pretendard` 웹폰트 적용
